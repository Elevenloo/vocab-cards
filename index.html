➕ 新增單詞

輸入英文，自動幫你翻成中文；兩個欄位都可以自己改。

📷 拍照 / 截圖 → 一次過認晒所有單詞

影功課、課本、單詞表都得。有填 API Key 就用 AI 視覺模型（最準，識得理解排版）； 冇填就自動用瀏覽器本地 OCR（免費、唔使註冊）。

📋 識別結果（可以直接改）

每行一組，用 | 或 Tab 或逗號分隔：apple | 蘋果。 亦可以直接手動 paste 你嘅單詞表入嚟。

💾 備份 / 匯出

資料全部儲喺你自己部機嘅瀏覽器（localStorage），唔會上傳去任何伺服器。 唯一例外：用 AI 識別／翻譯時，圖片同單詞會傳去你填嘅 API 供應商。
